# IT 2.0 — новая версия сайта

Новая реализация сайта Управления социальной политики Липецкой области на Laravel 12, Blade и MySQL. Разработка ведётся в отдельной ветке `it-2.0` и каталоге `it-2.0/`.

## Безопасность
- Не подключать приложение к производственной БД и не использовать её учётные данные.
- Создать отдельную пустую БД MySQL и отдельного пользователя для IT 2.0.
- Перед запуском миграций проверить локальный `.env`.
- Не переносить секреты и пароли старой CMS.
- Импорт данных будет отдельной процедурой после аудита схемы и резервного копирования.

## Установка
PHP 8.2+, Composer 2, MySQL 8.0+ и расширения Laravel 12 (PDO MySQL, mbstring, openssl, tokenizer, xml, ctype, json, bcmath, fileinfo).
1. Перейти в `it-2.0` и скопировать `.env.example` в `.env`.
2. Выполнить `composer install` и `php artisan key:generate`.
3. Создать отдельную пустую БД `it2` и пользователя MySQL.
4. Проверить параметры DB_* в локальном `.env`.
5. Только после проверки выполнить `php artisan migrate`.
6. Создать первого администратора: `php artisan it2:make-admin`.
7. Запустить `php artisan serve`.

## Тесты
Выполнить `composer test`. PHPUnit использует SQLite in-memory, не производственную БД.

## Текущий статус
Есть Laravel bootstrap/config, публичная Blade-оболочка, начальная схема CMS, защищённый вход администратора, проверка ролей/активности, ограничение частоты попыток входа, команда создания первого администратора и тесты доступа. Полноценные CRUD-интерфейсы, все старые модули, реальные формы обращений, файловый менеджер, импорт данных, аудит, резервное копирование, CI и end-to-end тестирование ещё впереди. Миграции и страницы-заглушки не являются признаком готовности соответствующих функций.
