# IT 2.0 — новая версия сайта

Новая реализация сайта Управления социальной политики Липецкой области на Laravel 12, Blade и MySQL. Разработка ведётся в отдельной ветке `it-2.0` и каталоге `it-2.0/`.

## Гарантии безопасности разработки
- Не подключать новую версию к производственной БД и не использовать её учётные данные.
- Для IT 2.0 создать отдельную пустую БД MySQL и отдельного пользователя.
- Миграции запускать только после проверки локального `.env`.
- Не переносить пароли, ключи и секреты из старой CMS.
- Импорт данных — отдельная процедура после аудита схемы и создания резервной копии.

## Требования
PHP 8.2+, Composer 2, MySQL 8.0+, расширения PHP для Laravel 12, включая PDO MySQL, mbstring, openssl, tokenizer, xml, ctype, json, bcmath и fileinfo.

## Установка локально
1. Перейти в каталог `it-2.0`.
2. Создать локальный `.env` на основе `.env.example`.
3. Выполнить `composer install` и `php artisan key:generate`.
4. Создать отдельную пустую БД `it2` и отдельного пользователя MySQL.
5. Проверить DB_HOST, DB_DATABASE, DB_USERNAME и DB_PASSWORD в локальном `.env`.
6. Только после проверки выполнить `php artisan migrate`.
7. Создать первого администратора командой `php artisan it2:make-admin`.
8. Запустить `php artisan serve` и открыть `http://127.0.0.1:8000`.

## Тестирование
Выполнить `composer test`. PHPUnit настроен на SQLite in-memory, поэтому тесты не обращаются к рабочей MySQL-базе.

## Реализовано в текущем срезе
- Laravel 12 bootstrap и базовые настройки MySQL.
- Публичная Blade-оболочка и адаптивная главная страница.
- Начальные страницы новостей и интернет-приёмной (пока информационные заглушки).
- Основа схемы CMS: страницы, меню, новости, текстовые блоки, баннеры, FAQ, опросы и обращения.
- Вход в административную зону, выход, проверка активности учётной записи и ролей admin/editor.
- Ограничение частоты попыток входа и CSRF-защита через стандартный web middleware.
- Интерактивная команда первичного создания администратора без предустановленного пароля.
- Feature-тесты сценариев доступа и авторизации.

## Не считать завершённым
Полноценные CRUD-интерфейсы, управление всеми модулями, пользовательские формы, файловый менеджер, импорт данных из старой CMS, резервное копирование, аудит действий, CI, браузерное тестирование и итоговая проверка на MySQL ещё не реализованы. Наличие миграций или страниц-заглушек не означает готовность этих функций.
