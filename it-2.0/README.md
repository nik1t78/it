# IT 2.0 — новая версия сайта

Новая реализация сайта Управления социальной политики Липецкой области на Laravel 12, Blade и MySQL. Вся новая разработка находится в отдельном каталоге it-2.0/ и отдельной ветке it-2.0.

## Безопасность
- Не подключать новую версию к производственной БД.
- Использовать отдельную пустую БД MySQL (по умолчанию it2) и отдельного пользователя.
- Не выполнять миграции на действующем сайте.
- Не переносить секреты и пароли из старой системы.
- Импорт данных — только отдельной контролируемой процедурой после аудита схемы и резервного копирования.

## Требования
PHP 8.2+, Composer 2, MySQL 8.0+, расширения Laravel 12, включая PDO MySQL, mbstring, openssl, tokenizer, xml, ctype, json, bcmath и fileinfo.

## Начало установки
Создать локальный .env из .env.example, выполнить composer install и php artisan key:generate. Затем создать отдельную БД it2, заполнить DB_* и только после проверки параметров запустить php artisan migrate и php artisan serve.

## Статус
Первый срез: Laravel bootstrap, маршруты, адаптивная публичная Blade-оболочка и заглушки главной, новостей и интернет-приёмной. Это каркас, не готовый сайт. Админка, полноценная аутентификация, CRUD, остальные модули, миграция данных, тесты и CI ещё не реализованы. Файлы-заготовки не считаются подтверждением готового сценария.
